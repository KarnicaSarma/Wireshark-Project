# Wireshark Display Filters in Kali Linux

## Introduction
Wireshark is a network protocol analyzer used to capture and analyze network packets.

## Aim
To capture and analyze network traffic using different Wireshark display filters.

## Requirements
- Kali Linux
- Wireshark
- Internet connection

## Filters Used
- HTTP
- DNS
- TCP
- UDP
- ICMP
- TLS
- IP Address
- Source IP
